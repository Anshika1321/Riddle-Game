# Riddle-Game
A fun and interactive console-based riddle game built with Java. Test your wits with a series of randomly chosen riddles, get helpful hints if you're stuck, and see how many you can solve!

▶How I Built This Riddle Game
Created a Project Folder
I began by creating a new folder named Riddle Game to hold all the files.

Created the HTML File
Inside the folder, I created an index.html file to house the entire game code.

Structured the Layout with HTML
I designed a simple interface including a title, a riddle display area, an answer input field, buttons for submitting and moving to the next riddle, and sections for feedback, hints, and score display.

Styled the Game with CSS
Using internal CSS (inside the <style> tag), I gave the game a dark theme, styled the container, buttons, and text to ensure a user-friendly experience.

Added Interactivity with JavaScript
I wrote JavaScript (within the <script> tag) to:

Randomly display riddles from a predefined array.

Check the user's input against correct answers.

Provide hints if the answer is wrong.

Display feedback and update the score.

Allow the user to load new riddles.

Tested Locally Using Live Server
I ran the project locally using Visual Studio Code and the Live Server extension to see real-time changes and ensure everything worked as expected.

▶How to Run This Project in Your Browser (Using VS Code + Live Server)
Prerequisites
Visual Studio Code installed

A modern internet browser (e.g., Chrome, Firefox)

▶Step-by-Step Guide
Download the Project Files
Download or clone the repository that contains the index.html file.

Open the Project Folder in VS Code

Launch Visual Studio Code

Go to File > Open Folder...

Select the folder where your HTML project is located

Install the "Live Server" Extension

Click on the Extensions tab (or press Ctrl+Shift+X)

Search for Live Server

Install the one developed by Ritwick Dey

Open the index.html File
In the Explorer panel, click on index.html to open it in the editor.

Run the Project with Live Server

Right-click inside the index.html file

Select "Open with Live Server"

A new browser window or tab will open, and your game will start running!
